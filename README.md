### Highlights

* Layered ASP.NET Core architecture
* REST API + MVC application
* ASP.NET Core Identity
* JWT, cookie, claim and policy-based authorization
* Entity Framework Core + SQL Server
* Background email processing
* Transactions and domain workflows
* Swagger / OpenAPI
* GitHub Actions CI

The repository also contains two supporting backend services:

**HonlightPay** — simulated payment gateway
**HonlightBank** — simulated banking service

Together they implement a complete payment flow with:

`JobBoard → HonlightPay → HonlightBank → Callback → Verification → Activation`

including payment verification, callback validation, idempotency, ownership checks, refunds, and transaction-safe activation.
